# 创建 PC 端页面模板

你正在帮助用户快速创建一个 HR 业务 PC 端页面模板。

## 用户输入

$ARGUMENTS

## 执行流程

### Step 1: 确定目标文件名

- 如果用户指定了文件名，使用用户指定的文件名（确保以 `.html` 结尾）
- 如果用户未指定，默认使用 `template.html`

### Step 2: 读取模板文件

读取 Skill 中的标准 PC 模板文件：

```
hr-vue-next/assets/template.html
```

### Step 3: 复制模板到当前工程目录

将模板文件内容完整写入到用户当前工程目录下，使用 Step 1 确定的文件名。

- 目标路径：`{用户工程根目录}/{文件名}`
- 如果目标文件已存在，**先提醒用户**，确认后再覆盖

### Step 4: 完成提示

告知用户：

1. ✅ 模板文件已创建，文件路径
2. 📝 模板包含的技术栈：Vue 3 + TDesign + HR-Vue-Next（UMD 方式引入）
3. 🔧 可根据业务需求修改模板内容
4. 💡 如需使用具体的 HR 组件，可以使用 `/hr-vue-next` 命令获取组件使用指导

## 注意事项

- 直接复制完整模板内容，不要做任何修改
- 模板文件是一个完整的、可直接在浏览器打开的 HTML 文件
- 如果用户提供了页面标题等自定义信息，可以在复制后帮助用户修改 `<title>` 等基本信息
